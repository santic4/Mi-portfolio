# Actualización: CV descargable

Este paquete agrega una sección de currículum al portfolio y deja disponibles los dos PDF para descarga directa.

## Archivos incluidos

- `app/page.tsx`
- `app/globals.css`
- `public/cv/Santiago_Canu_CV_Full_Stack_ES.pdf`
- `public/cv/Santiago_Canu_CV_Full_Stack_EN.pdf`

## Cómo aplicarlo

Copiá los archivos respetando las mismas rutas dentro de tu proyecto. Luego ejecutá:

```bash
npm run build
```

La sección nueva se encuentra en `#cv`. Incluye un acceso desde la navegación, un botón en la portada y dos descargas: CV en español y CV en inglés.
